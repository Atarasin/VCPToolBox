# VCP 多媒体工具箱能力收纳
这里收纳了各种强大的多媒体生成与控制工具。

[===vcp_fold:0.3===]

## 1. 显影图像生成/编辑 (VizDevelop) ——首选生图通道——
接入显影（viz-develop）图像服务：文生图、图片编辑、源图上传与任务查询。当前首选且唯一启用的生图工具，文生图与图片编辑均走此通道。生成/编辑为付费操作，必须有用户明确要求；提交后同步等待约 35 秒，快模型多数当轮直接出图；未完成则凭 operationId 轮询（可用 VCPSleep 睡 1~2 分钟自唤醒，或 timely_contact 定时查询后用 TimedTaskQuery 取回）；产物为公网图片 URL（原样透传，不落盘）。
注：ZImageTurboGen / DoubaoGen / NanoBananaGen2 / GPTImageGen 等旧生图插件已停用，请勿调用。
tool_name:「始」VizDevelop「末」,
command:「始」generate_image「末」,
operationId:「始」(必需) 幂等键，格式如 img-主题-v1；重试必须复用同一 ID，新 ID = 新付费意图「末」,
display_title:「始」(必需, ≤60字符) 图片是什么；公开信息，禁止密钥/隐私「末」,
display_description:「始」(必需, ≤240字符) 为什么生成、准备用在哪里「末」,
prompt:「始」(必需) 图片描述原文，原样透传不改写「末」,
model:「始」(可选) 省略则走服务默认模型；不确定可用命令 list_image_models 现查，不要凭记忆猜「末」

编辑已有图片：command:「始」edit_image「末」 + 源图二选一 image_input_id（上传所得）或 image_artifact_token（已发布产物），其余必填项同上；可选 mask_input_id / markup_input_id（至多一个）。
免费命令（command 参数）：health（探活）、list_image_models（模型目录）、create_image_input（上传源图：contentBase64 必须纯 base64，带 data: 前缀会被拒绝）、get_image_operation（凭 operationId 查任务状态与图片 URL）。
纪律：零自动重试；查询返回 unknown 状态时绝不换 ID 重发，须原样告知用户人工核对。

用于控制服务器音乐播放。

songname:「始」星の余韻「末」 // 注意观察当前服务器音乐列表是否包含曲目，可用LightMemo检索。

## 4. Grok 视频生成 (GrokVideoGen)
马斯克出品，极速生成 6 秒视频，包含高质量配音，支持 NSFW。
tool_name:「始」GrokVideoGen「末」,
image_url:「始」(必需) 底图链接「末」,
prompt:「始」(必需) 描述视频内容和配音「末」,
video_url:「始」(可选) 用于视频续写「末」

### 视频拼接
command:「始」concat「末」,
video_url1:「始」[第一个URL]「末」,
video_url2:「始」[第二个URL]「末」
